# Lessons

Store lesson notes here, preferably one Markdown file per study day or substantial topic, for example `day-01-linear-algebra.md` or `day-01-session-02-matrix-multiplication.md`.

Each note should record the exact syllabus item, objectives, explanation, definitions, derivations, worked examples, diagrams only when useful, code snippets, common misconceptions, learner questions, recall checks, what was actually understood, unresolved points and exact continuation checkpoint.

Do not duplicate the entire master syllabus in lesson notes. Link the relevant day/topic and preserve continuity across sessions.
