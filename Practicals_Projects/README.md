# Practicals and Projects

Keep all practical notebooks, scripts, datasets references, experiment outputs and project deliverables in this one folder. Use clear names such as `day-04-classical-ml/`, `project-01-linear-regression/` and `project-08-rag-assistant/` as needed; do not create a large hierarchy in advance.

For each practical, record objective, environment/dependencies, dataset/source/license, implementation, execution evidence, outputs/metrics, errors and fixes, interpretation, limitations and next steps. Distinguish code written from code successfully executed. Do not commit secrets, credentials or private keys. Prefer small reproducible datasets and CPU-friendly alternatives where appropriate.

Portfolio projects from the blueprint: (1) linear regression from scratch, (2) classical ML prediction system, (3) ANN from scratch and PyTorch, (4) image classifier, (5) sequence prediction/classifier, (6) mini transformer/attention, (7) open-weight LLM adaptation experiment, (8) RAG document assistant, (9) optional agent extension.
